# SQL Task 3 — Data Analysis Using MySQL

## Objective
Use SQL to analyze an E-commerce database and extract insights using joins, subqueries, views, and aggregate functions.

## Files Included
- ecommerce.sql — database creation script
- task3_queries.sql — all SQL queries used in the task
- screenshots/ — outputs of each query
- README.md — documentation

## 🛠 Tools Used
- MySQL Server
- MySQL Workbench

## SQL Topics Covered
- SELECT, WHERE, ORDER BY
- GROUP BY with SUM, AVG
- INNER JOIN, LEFT JOIN, RIGHT JOIN
- Subqueries
- Views
- Indexes for optimization
- Handling NULL values

## Key Insights
- Computed total revenue by category
- Found customers who never placed orders
- Built ARPU (Average Revenue Per User)
- Created an analysis view for simplified reporting
