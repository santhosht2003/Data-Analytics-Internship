# 📊 Internship Task 2: Data Visualization & Storytelling

## 🎯 Objective
To analyze the Superstore dataset using Power BI/Tableau and create meaningful visualizations that tell a clear business story.

---

## 🛠 Tools Used
- Power BI Desktop
- Sample - Superstore.csv dataset

---

## 📈 Visualizations Created
1. **Sales by Category** – Bar Chart  
2. **Monthly Sales Trend** – Line Chart  
3. **Profit by Region** – Donut Chart  
4. **Top 10 Products by Sales** – Horizontal Bar  
5. **Profit vs Sales** – Scatter Plot  
6. **Sales by State** – Filled Map  

---

## 📌 Key Insights
- Technology category generates the highest sales.  
- Western region provides the highest profit contribution.  
- Sales spike during November and December.  
- Some high-selling products show negative profit → discount/pricing issue.  
- California dominates in total sales across the U.S.
